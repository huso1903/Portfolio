SAÉ – Développement d’un Outil de Reporting pour l’Analyse d’Espace Disque

Description du Projet Dans le cadre de la SAÉ 1.05, nous avons développé un outil de reporting destiné à localiser les fichiers les plus volumineux d’un répertoire donné. L’objectif principal était de répondre à un problème courant : le manque d’espace disque sur les ordinateurs, pouvant empêcher le bon fonctionnement du système. L’outil, développé en Python avec PyQt5, permet de : Sélectionner un répertoire via une interface graphique, Réaliser un inventaire récursif de tous les fichiers présents, Extraire et trier les 100 plus gros fichiers, Générer une visualisation sous forme de camembert interactif, Produire un script PowerShell personnalisé pour supprimer les fichiers cochés par l’utilisateur.
